# SquareSnap privacy policy

Effective 2026-11-16. This policy covers SquareSnap on every platform: the Microsoft Store version, the WinGet and zip versions for Windows, and the Linux version.

## The short version

SquareSnap collects nothing, sends nothing and connects to nothing. Everything it does happens on your own computer.

## What SquareSnap does with your data

- **No personal information.** SquareSnap doesn't collect, store or share any personal information.
- **No network access.** SquareSnap makes no network connections. It has no telemetry, analytics, crash reporting, advertising, accounts or automatic updates. (The Microsoft Store version is updated by the Microsoft Store, under Microsoft's own privacy policy.)
- **Your screen stays yours.** SquareSnap reads the screen only when you start a capture (with the button, the hotkey, the tray or a command). The picture goes only where you choose: the clipboard and/or a new file in your save folder. It is never uploaded or sent anywhere.
- **What it keeps on your computer.** SquareSnap saves its settings (such as the save folder, output size, file format, hotkey and the last square you captured) and a troubleshooting log in its own folder: `%APPDATA%\SquareSnap` on Windows (the Microsoft Store version uses its own private copy of that folder, which uninstalling removes), and `~/.config/SquareSnap` on Linux. The log records what SquareSnap did, file paths and screen coordinates, never the pictures themselves. `squaresnap paths` shows exactly where these files are. You can delete them at any time.
- **Help menu link.** If you choose Help > Read Me (opens GitHub), SquareSnap opens the project's web page in your browser. That is your browser visiting GitHub, under GitHub's privacy policy; SquareSnap itself sends nothing.

## Children

SquareSnap collects no information from anyone, including children.

## Changes

If this policy ever changes, the new version will be published here with a new effective date. The project's history on GitHub shows every earlier version.
